# 🔀 BPMN Process Diagrams

A collection of business process models built with **BPMN** (Business Process Model and Notation) in [draw.io](https://www.drawio.com/), modelling everyday service processes end-to-end. Diagrams and descriptions are in Polish.

## 📌 What's Inside

| Process | Files |
|---|---|
| Bank process | [`Bank/`](Bank) |
| Internet installation service order & setup | [`Poglądowy proces zamówienia usługi- instalacji internetu. Oraz sama jego instalacja/`](<Poglądowy proces zamówienia usługi- instalacji internetu. Oraz sama jego instalacja>) |
| Parcel locker (paczkomat) handling | [`Proces obsługi paczkomatu/`](<Proces obsługi paczkomatu>) |
| Recruitment process | [`Proces rekrutacji/`](<Proces rekrutacji>) |
| ATM cash withdrawal | [`Proces wypłacenia pieniędzy z bankomatu/`](<Proces wypłacenia pieniędzy z bankomatu>) |
| Online store shipment order | [`Proces zamówienia przesyłki ze sklepu internetowego/`](<Proces zamówienia przesyłki ze sklepu internetowego>) |
| Doctor's office visit | [`Wizyta u Lekarza/`](<Wizyta u Lekarza>) |
| Order process | [`Zamowienie/`](Zamowienie) |

Each folder contains the editable diagram source (`.drawio`) and a rendered image (`.png`) of the same process.

## 🚀 Viewing & Editing

* Quick look: open any `.png` directly in this repo.
* Edit: open the `.drawio` file at [app.diagrams.net](https://app.diagrams.net/) (or the desktop/VS Code draw.io app) — File → Open From → Device.
